    About GitHub Pulse

    One project, two layers. The data side collects public GitHub activity every day and turns it into SQL tables. The AI side lets you ask questions in plain English and streams back answers with source links.

    DataGH Archive, a free public record of GitHub events. Nothing from EY.
    Why it fitsIt covers Docker, CI, Postgres, FastAPI, Redis, workers and LLM APIs, the gaps AI backend roles ask about.
    Interview line"I built a backend that ingests GitHub events into Postgres, with an AI assistant on top that streams cited answers, caches, runs background jobs and has a measured accuracy."

    The first answer comes from SQL. The second comes from searching issue text.

    Keep it small, cheap and clean
    SizeCheck a GH Archive file size before downloading. Take one hour per day and keep three event types early: WatchEvent, IssuesEvent, IssueCommentEvent.
    CostSpend limit on the LLM account. Use a free local embedding model.
    PrivacyEvents contain public usernames. Store no emails or personal details and show aggregates in the demo.
    SecurityTreat retrieved issue text as data, never as instructions to the model.
    Words you will meet
    IdempotentRunning a step twice gives the same result as once. Makes reruns safe.
    Star schemaOne fact table of events plus small lookup tables (repo, actor, date).
    EmbeddingNumbers that represent the meaning of text. Similar texts get similar numbers.
    ChunkingSplitting long text into pieces that can be embedded and retrieved alone.
    RAGFind relevant text first, then give it to the model so answers rest on real sources.
    Structured outputThe model returns JSON matching a schema, so code can rely on it.
    Tool useThe model asks to run one of your functions. You run it and send back the result.
    SSEServer-Sent Events. One open HTTP response sends pieces as they are ready.
    Cache hit rateShare of requests answered from Redis without calling the model.
    WorkerA separate process that takes jobs from a queue so the API replies at once.
    Hit rate at kHow often the right source is in the top k results.
    EvalFixed questions with known answers you re-run to measure quality.
    TraceA record of one request: retrieval, tools, tokens, time and cost.

      C++: DSA

        Reference

        How to practise

        Try each problem alone for 20 minutes. Write the plan in a comment before coding. If stuck, watch the NeetCode video, close it, and code it yourself. Re-solve from memory the next day. Aim for about 5 problems a week, 60 or more in 90 days.

        C++ cheat sheet
        Hash mapunordered_map<int,int>, unordered_set
        Min-heappriority_queue<int,vector<int>,greater<int>>. The default is a max-heap.
        Sortsort(v.begin(), v.end()), with a lambda for custom order.
        Searchlower_bound and upper_bound on sorted ranges.
        Queue/stackqueue, stack, deque. Pass big containers by reference.
